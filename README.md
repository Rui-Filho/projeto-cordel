# Projeto Cordel

https://rui-filho.github.io/projeto-cordel/#

Projeto desenvolvido durante os estudos de HTML e CSS, inspirado no poema "Cordel Moderno", de Milton Duarte.

O objetivo foi praticar estruturação de páginas, estilização com CSS e recursos como imagens de fundo e efeito parallax.

## Tecnologias

- HTML5
- CSS3

## Status

Projeto de estudo concluído.
